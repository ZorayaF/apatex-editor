# Registro de avances

## [0.1.0] - 2026-01-31

### Añadido
 
- **Estructura del Proyecto:** Creación de la base del programa usando Electron y React.

- **Gestión de Información:** Sistema para guardar el texto como una lista de elementos (Títulos, Párrafos) de forma independiente a su diseño.

- **Organización por Pantallas:** Creación de una pantalla de inicio para gestionar archivos y una pantalla de editor para escribir.

- **División de Trabajo:** El editor ahora tiene tres secciones claras:

  - Izquierda: Índice de capítulos para navegar rápido.
  - Centro: Área de escritura que simula la hoja de papel.
  - Derecha: Panel de ayuda y reglas de la universidad.

- **Diseño Inicial:** Aplicación de las primeras reglas de la Politeca (Letra Times New Roman, tamaño 12 y espacios entre líneas).


### Configuración

- Configuración de seguridad y respaldo en la nube (GitHub).

- Preparación del entorno de desarrollo en Linux (Ubuntu/WSL2).
